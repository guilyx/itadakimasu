# itadakimasu

Our Japan trip guide, 28 Nov – 12 Dec 2026: Kyoto, Nagano, Shibu Onsen, Takayama and Tokyo.

**Live site:** https://guilyx.github.io/itadakimasu/

What's inside `index.html`:
- Route map you can play day by day
- Hotel options per stop in three budgets (Booking.com prices checked 20 Nov 2026, with photos)
- Trip budget planner: pick a hotel per stop, set a daily spend, see the cost per person
- Daily plan, transport, logistics and booking checklist

Hotel photos in `img/` are from each property's Booking.com page. Prices change, so check before booking.

Every push to `main` republishes the site to the `gh-pages` branch.
